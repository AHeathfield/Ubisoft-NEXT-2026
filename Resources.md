# Potentially useful resources
- This website has links to textbooks https://www.realtimerendering.com/intersections.html


## Resources I used for learning
- [Has YT Playlists explaining Game Dev Math concepts](https://www.youtube.com/@JorgeVinoRodriguez)
- [The Cherno](https://www.youtube.com/watch?v=rUxZ5N77M5E&t=575s), took some ideas from his mini application architecture series
- [LazyFoos SDL3](https://lazyfoo.net/tutorials/SDL3/index.php), good for understanding bigger concepts like the game loop and how low level things work a bit better (good starting point I used)
- [javidx9 (formerly OneLoneCoder)](https://www.youtube.com/watch?v=ih20l3pJoeU) has a really good series on low level 3D rendering
- [Godot GitHub](https://github.com/godotengine/godot), it's good for seeing how code is organized, and just to get an idea of things I would need, I also am use to using Godot so getting things similar to it helps
- [Godot Documentation](https://docs.godotengine.org/en/stable/), good for seeing the use purposes of certain nodes
- [Game Physics Cookbook](https://www.amazon.com/Game-Physics-Cookbook-Gabor-Szauer/dp/1787123669) used this to help come up with intersection tests on 3D shapes.

- [GDC Vault article on Bounding Volume Hierarchies](https://gdcvault.com/play/1026269/Math-for-Game-Developers-Dynamic) used this to help understand how BVH work in collision detection
